# 🎮 Game Battle - Текстовая RPG игра

Текстовая RPG игра с выбором расы, красивыми анимациями и цветным оформлением в консоли.

## 🚀 Быстрый старт

### Установка и запуск

```bash
# Клонировать репозиторий
git clone <your-repo-url>
cd game_battle

# Установить зависимости
npm install

# Запустить игру
make run
